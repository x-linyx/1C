## Описание решения

Состояние каждого хода хранится как `UNKNOWN`, `OK` или `BROKEN`.

После `LOOK` состояния всех ходов из текущего зала обновляются.

Вес хода определяется следующим образом:

1) `0`, если ход цел;
2) `1`, если ход обвалился;
3) `1 - p`, если состояние неизвестно.

Для поиска маршрутов используется алгоритм Дейкстры по данным весам.

Для каждого маршрута вычисляется оценка
[
\sum profit - day_cost \cdot expected_days,
]
где сумма берётся по ещё не посещённым залам маршрута.

Выбирается маршрут с максимальной положительной оценкой. Если такой маршрут отсутствует, выполняется `END`.

После каждого действия маршрут вычисляется заново. После `CLEAR` текущей вершиной считается вход, а очищенный ход -- целым.
